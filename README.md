# Rage of Fight

یک شوتر اول‌شخص موبایل‌محور با رابط فارسی، ساخته‌شده با **Three.js + Vite** و آمادهٔ بسته‌بندی با **Capacitor**. هدف فعلی ساخت یک نسخهٔ عمودیِ قابل‌آزمایش است: ابتدا تمرین و بقا در موج‌های زامبی، سپس بازی شبکهٔ محلی.

> این پروژه یک پیاده‌سازی مستقل با هندسه و کد خودش است؛ دارایی‌ها، نقشه‌ها، نام‌ها و داستان Call of Duty را کپی نمی‌کند. شبه‌کدهای استخراج‌شده از APK بتا در `recovered/apk-beta-native/` سورس اصلی Unity نیستند و مستقیماً در این پروژه استفاده نشده‌اند.

## وضعیت بازی

- **تمرین آفلاین:** شش ربات مسلح که به بازیکن نزدیک می‌شوند، شلیک می‌کنند و پس از حذف دوباره ظاهر می‌شوند.
- **بقای زامبی آفلاین:** موج‌های پیوسته با تعداد، سلامتی، سرعت و آسیب رو‌به‌افزایش؛ سقف تعداد زامبی‌های هم‌زمان برای اجرای روان‌تر روی موبایل.
- **سلاح‌ها:** تفنگ تهاجمی، تپانچه و شات‌گان؛ خشاب، شارژ مجدد، لگد، پراکندگی، افت آسیب با فاصله و هدشات.
- **کنترل موبایل:** حرکت با جوی‌استیک لمسی و نگاه با کشیدن انگشت در نیمهٔ راست صفحه؛ دکمه‌های شلیک، پرش، خشاب و تعویض سلاح.
- **رابط فارسی:** منو، وضعیت بازی، موج و اعداد فارسی/راست‌چین.
- **شبکهٔ محلی:** در برنامهٔ مرحلهٔ بعد است؛ میزبان/پیوستن هنوز در این نسخه فعال نشده است. منو این وضعیت را صریح نشان می‌دهد.
- محیط و مدل‌های اولیه رویه‌ای و سبک‌اند؛ این نسخه هنوز کیفیت بصری یا محتوای یک بازی کامل در مقیاس Call of Duty را ندارد.

## اجرا در وب

نیازمندی: Node.js 20 یا جدیدتر.

```bash
npm install
npm run dev
```

آزمون منطق برنامهٔ موج‌ها:

```bash
npm test
```

ساخت وب:

```bash
npm run build
npm run preview
```

## ساخت APK آزمایشی اندروید

نیازمندی‌ها: JDK 21، Android SDK و ابزارهای build اندروید. پوشهٔ Android باید فقط یک‌بار ساخته شود:

```bash
npm install
npx cap add android       # فقط بار اول
npm run build
npx cap sync android
cd android
./gradlew assembleDebug
```

APK آزمایشی در `android/app/build/outputs/apk/debug/app-debug.apk` ساخته می‌شود. اجرای `assembleDebug` در محیط فعلی هنوز انجام نشده، چون JDK و Android SDK در آن موجود نیستند.

## کنترل‌ها

| WASD یا کلیدهای جهت‌دار | حرکت |
| ماوس | نگاه و نشانه‌گیری |
| کلیک چپ | شلیک؛ نگه‌داشتن برای رگبار تفنگ تهاجمی |

| R | تعویض خشاب |
| Space | پرش |
| موبایل: جوی‌استیک چپ | حرکت |
| موبایل: کشیدن انگشت در سمت راست | نگاه کردن |
| موبایل: دکمه‌های اکشن | شلیک، پرش، خشاب و تعویض سلاح |

## ساختار پروژه

- `src/main.js` — صحنه، ورودی، منو، حلقهٔ بازی و جریان شروع/مکث
- `src/World.js` — آرنای تمرین، موانع، نورها، pickupها و محل spawn
- `src/Player.js` — حرکت، برخورد و سلامتی بازیکن
- `src/Weapon.js` — سه سلاح و ثبت اصابت
- `src/EnemyManager.js` — رفتار ربات‌ها، زامبی‌ها و موج‌ها
- `src/HUD.js` — رابط وضعیت فارسی
- `src/collision.js` — برخورد و خط دید
- `test/gameModes.test.js` — آزمون‌های برنامهٔ موج زامبی

فایل‌های `recovered/apk-beta-native/` فقط برای بررسی ساختار APK بتا هستند؛ آن‌ها سورس قابل‌کامپایل Unity یا جایگزین سورس این پروتوتایپ نیستند.
